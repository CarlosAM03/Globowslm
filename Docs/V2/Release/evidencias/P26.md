# P26 — Cierre académico de Globows LM 2.0.0

Autorización `APPROVE-GLOBOWS-V2-RELEASE`. Base de integración `f0e30b54c621c3e69e972c0224a00ca5a8b8fd90`. P25 completó el respaldo y las comprobaciones cloud sobre esa base.

Los cuatro JSON de frontend y API se compararon estructuralmente con la base. Los únicos cambios fueron `version` en los manifiestos y `version` más `packages[""].version` en los lockfiles. Código, migraciones y dependencias de runtime y QA quedan congelados.

GitHub CI debe aprobar el PR y luego el SHA integrado en `main`. Antes de etiquetar, comprobar que ese mismo SHA se encuentra activo en Vercel y Render, con readiness, rutas públicas, acceso anónimo denegado a funciones administrativas y `noindex`. El tag anotado y GitHub Release deben apuntar al SHA validado. El registro con los IDs y las verificaciones remotas se publica junto a la GitHub Release, una vez efectuadas.

El cierre comprende únicamente la instalación académica y validación inicial no comercial. Los pendientes editoriales de V1 permanecen vigentes. La operación comercial requiere una infraestructura autorizada para ese uso. La autonomía del frontend queda reservada para v2.0.1.
