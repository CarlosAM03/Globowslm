## Runtime

El backend en `backend/Dockerfile` ejecuta `node dist/src/main.js` como usuario `node`. Usa `PORT`, `DATABASE_URL`, `APP_ORIGIN` y `MEDIA_ROOT`. La migración se ejecuta con `npm run db:deploy` en la etapa de migración. Compose monta `/var/lib/globows/media`, importa V1 bajo demanda y mantiene los fixtures de QA locales. Next usa `CMS_API_INTERNAL_URL` desde servidor, configura CSP con `CMS_MEDIA_ORIGIN` y mantiene BFF JSON cerrado con CORS específico de multimedia. Los bytes viajan directamente entre el navegador y la API. [ADR](../../ADR.md) [Operación](../../Operacion-local-y-produccion.md)
