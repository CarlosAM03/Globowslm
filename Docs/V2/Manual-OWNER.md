# Manual del panel editorial

Entra a [la administración local](http://127.0.0.1:3100/admin/login) con la cuenta OWNER que se provisionó en Docker. En pantallas pequeñas abre **Menú** para cambiar de módulo. El panel inicial muestra actividad editorial y el estado del contenido.

| Módulo | Operación habitual |
|---|---|
| Institucional | Edita portada, historia, trayectoria, contactos, preguntas frecuentes y SEO. |
| Servicios | Ordena servicios y tipos de evento. Vincula la imagen y define el interés que se enviará por WhatsApp. |
| Galerías | Publica primero la categoría. Agrega las fotos, reordénalas y revisa el texto alternativo y los pies. |
| Multimedia | Sube fotos o videos, revisa el archivo y su texto alternativo. El panel indica cuando una referencia bloquea el retiro o borrado. |
| Formación | Registra oferta presencial, medios opcionales y un motivo de consulta. |
| Certificaciones | Completa organismo y evidencia según corresponda. Confirma la verificación antes de publicar. |
| Blog | Edita el resumen, categorías, etiquetas, portada y bloques. El slug queda fijo desde la primera publicación. |
| Publicaciones | Filtra por tipo y estado, consulta el historial y copia una revisión al borrador. |

1. Guarda el borrador y abre **Previsualizar**. Confirma los textos, destinos de contacto, imágenes y orden.
2. Publica y recarga la página pública. Las ediciones posteriores vuelven a quedar en borrador hasta publicar.
3. Usa **Retirar** para quitar de la vista pública una entrada que pueda retirarse. Conserva historial. **Archivar** también retira y guarda el contenido para una restauración posterior.
4. Para recuperar una revisión abre **Publicaciones**, selecciona la entrada, abre la revisión y usa **Copiar al borrador**. Previsualiza y publica cuando esté lista.
5. Si se informa un conflicto de versión, actualiza la entrada y revisa los cambios antes de guardar de nuevo. Si hay dependencias en uso, retira o actualiza primero las publicaciones que las referencian.

Para probar el flujo sin editar el catálogo aprobado, crea un borrador con un nombre que identifiques como prueba. Comprueba el sitio público en otra pestaña. Retira los datos de prueba publicados al terminar la revisión.
