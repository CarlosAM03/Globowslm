# P03 — Dominio CMS y flujo editorial

- R10. Base `0057851e705093c9c96feb05a0d8284d10d55f51`, rama `patch/v2/P03`. Docker local con PostgreSQL 16.16 y Prisma 7.10.1.
- Se agregó una migración Prisma para las entradas, revisiones, media, referencias de borrador/revisión y auditoría. El índice único por tipo y slug, la FK compuesta de revisión activa y las FKs restrictivas se aplican en PostgreSQL. El servicio conserva una copia publicada por revisión y el historial tras retirarla. La restauración vuelve a dejar el borrador disponible para edición.
- Las mutaciones comprueban la versión del borrador e incrementan su valor en transacción serializable. Se comprueban tipo, estado y disponibilidad de referencias dentro de la transacción. La auditoría forma parte del mismo commit de datos. Las versiones obsoletas reciben un conflicto con la versión actual.
- Se validan los nueve tipos con DTOs estrictos, límites y listas de referencias. Zod 4.6.7 (MIT) quedó fijado con la integridad verificada en npm. La resolución del lock reportó cero hallazgos. Los slugs se validan por separado en la entrada y se mantienen tras la primera publicación.
- Gate preliminar de API en `globows-v2-p03-check`: TypeScript, lint y build correctos, 6 unitarias y 8 integraciones aprobadas después de corregir el UUID de entrada. En la primera ejecución la migración aplicó desde cero, pero cuatro pruebas de persistencia fallaron al omitir Prisma el UUID que participa en una FK compuesta. La creación lo asigna explícitamente y conserva la FK.
- La prueba de concurrencia produjo una edición y un conflicto. Las pruebas de PostgreSQL confirmaron bloqueo por referencias activas y FKs, inmutabilidad de snapshots, reversión de una publicación si falla la escritura de auditoría y recuperación del borrador. Una petición sin sesión a la ruta administrativa de contenido devolvió 404 porque en P03 aún no se registra el controlador.
- El alcance de este patch es el servicio de dominio. La autenticación, el acceso web y el selector de media se incorporan en sus patches.
