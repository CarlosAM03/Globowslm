# P06 — CMS institucional

- R03. Base `6f41f4498aee8f96e9412888f29a5127d82bad88`, rama `patch/v2/P06`. Docker Compose local con PostgreSQL 16.16, NestJS y Next 16.4.6.
- El editor institucional guarda nombre, fundadora, presentación, historia, filosofía, trayectoria, contactos, FAQ y metadatos. Los contactos vacíos se omiten. La vista previa muestra el borrador guardado y la publicación crea una revisión independiente.
- La ruta institucional y el BFF requieren sesión OWNER. Las mutaciones comprueban origen/CSRF, límites JSON y versión de concurrencia. El preview usa `no-store`. Las URLs sociales se validan por origen HTTPS y proveedor.

El caso HTTP rechazó peticiones anónimas, falta de CSRF y un host social inválido.
