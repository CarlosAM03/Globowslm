- El BFF limita operaciones, identificadores, parámetros y destinos HTTP locales. Las pruebas comprueban respuestas anónimas, origen y CSRF, errores sin credenciales, cabeceras del build y tokens de sesión. El backend conserva el rate limit y mantiene desactivada la confianza implícita en cabeceras de proxy.
- La ruta de imagen pública admite seis anchos fijos, con reescalado limitado y caché de bytes en memoria. Cada lectura vuelve a consultar la elegibilidad del snapshot. Los originales conservan el streaming y los rangos. Los derivados evitan que el optimizador de Next prolongue la visibilidad después de retirar una publicación.
- La política pública conserva `form-action 'none'`. El panel y su BFF admiten `form-action 'self'` y el origen multimedia configurado. Next y Tailwind conservan los permisos para inline existentes en el build. El gate verifica `noindex`, `DENY`, `nosniff` y referrer.
- El flujo Chromium de P15 usa el stack real. Recorre panel, carga de WebP, edición de artículo, publicación, lectura pública con bytes y retiro. Comprueba teclado, nueve anchos y axe para el sitio, login, panel y artículo.
- La primera reconstrucción de P15 detectó que el checkout de Windows convirtió a CRLF el script de entorno de Docker. La imagen normaliza ese archivo durante el build y copia la versión normalizada al runtime.
